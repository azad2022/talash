# نرم‌افزار مدیریت گالری طلا و جواهرات (طلاش) 🪙✨

**طلاش (Gildar Gold Management System)** یک نرم‌افزار جامع، تخصصی و کاملاً نیتیو برای پلتفرم اندروید است که متناسب با نیازها، سنت‌ها و استانداردهای روز صنف طلا و جواهر ایران طراحی و پیاده‌سازی شده است. این نرم‌افزار امکان مدیریت فروش و فاکتور، انبارداری هوشمند، یکپارچگی با سخت‌افزارهای فروشگاهی (ترازوی دیجیتال، بارکدخوان، پرینتر حرارتی و لیبل‌پرینتر)، بستن روز و تراز روزانه، و محاسبات دقیق بازار طلا را فراهم می‌کند.

---

## 💎 امکانات و قابلیت‌های تخصصی زرگری

### ۱. محاسبه قیمت طلا و نرخ‌گذاری استاندارد صنف
* **محاسبه دقیق طبق قانون جدید مالیات بر ارزش افزوده (مصوب دی‌ماه ۱۴۰۰):**  
  اصل طلای خام از مالیات بر ارزش افزوده معاف است؛ سیستم مالیات (۹٪) را فقط و فقط به مجموع «اجرت ساخت + سود تک‌فروشی (۷٪ قانونی اتحادیه)» اختصاص می‌دهد.
* **تبدیل زنده مظنه (مثقال ۱۷ عیار) به گرم ۱۸ عیار:**  
  برقراری ارتباط دوطرفه و لحظه‌ای میان «مظنه بازار (یک مثقال طلای ۷۰۵)» و «قیمت هر گرم طلای ۱۸ عیار (۷۵۰)» بر اساس فرمول استاندارد اتحادیه:
  $$\text{هر گرم طلای ۱۸} = \frac{\text{مظنه}}{4.3318}$$
* **پشتیبانی از عیارهای سفارشی و گوناگون:**  
  پشتیبانی از عیار ۱۸ (۷۵۰)، ۲۱ (۸۷۵)، ۲۲ (۹۱۶)، ۲۴ (۹۹۹) و محاسبه ضریب عیار به صورت اعشاری و دقیق.
* **انواع اجرت ساخت:**  
  امکان تعریف اجرت به صورت **درصدی (%)** از ارزش طلای خام یا **مبلغ ثابت به ازای هر گرم (تومان/گرم)**.
* **کسر وزن نگین و متعلقات:**  
  امکان تفکیک وزن ناخالص کالا از وزن نگین یا سنگ‌های تزئینی و محاسبه خودکار وزن خالص طلا.

### ۲. طلای آبشده، شمش، سکه و دارایی‌های ارزی
* **دسته‌بندی تخصصی دارایی‌ها:**  
  تعریف کالاهای گالری در دسته‌های اختصاصی از جمله: طلای ۱۸ عیار، طلای ۲۴ عیار، طلای آبشده نقدی، شمش طلا، سکه تمام بهار آزادی، سکه امامی، نیم سکه، ربع سکه، سکه گرمی، طلای متفرقه و مستعمل، و ارزهای سرمایه‌ای (دلار، تتر، یورو، درهم، پوند).
* **ارزش‌گذاری خودکار دارایی‌های گالری:**  
  محاسبه ارزش کل موجودی انبار بر مبنای نرخ‌های لحظه‌ای و بدون اعمال اجرت و سود ناخواسته برای مسکوکات و آبشده.

### ۳. حالت ویژه «خرید طلای مستعمل و متفرقه از مشتری» (تعویض طلا)
* **محاسبه خرید طلای دست‌دوم:**  
  محاسبه ارزش طلای کارکرده بدون اجرت ساخت، بدون سود فروشنده و با معافیت کامل از مالیات بر ارزش افزوده.
* **انتخاب عیار عرف بازار:**  
  امکان انتخاب سریع عیار خرید عرف بازار: ۷۵۰ (۱۸ عیار کامل)، ۷۴۰ (عرف استاندارد بازار طلافروشان) و ۷۳۵ (طلای فرسوده یا جوش‌دار).
* **انتقال مستقیم به فاکتور:**  
  امکان ثبت خرید به عنوان قلم فاکتور جهت تسویه یا تعویض با طلای نو تنها با یک کلیک.

### ۴. صدور فاکتور و مدیریت فروش
* **صدور فاکتور نقدی و اقساطی:**  
  امکان تعیین پیش‌پرداخت، تعداد ماه‌های اقساط، و سرشکن‌کردن دقیق ریالی اقساط.
* **نمایش و کنترل مجموع وزن طلای فاکتور:**  
  محاسبه و نمایش سرجمع وزن خالص طلای اقلام جهت تطبیق با ترازوی پیشخوان.
* **انعطاف در انتخاب مشتری:**  
  انتخاب مشتری ثبت‌شده در دفترچه یا صدور سریع فاکتور برای «مشتری متفرقه».

### ۵. بستن روز کاری و تراز طلافروشی (Daily Closing)
* **تراز روزانه دارایی و فروش:**  
  محاسبه جمع فروش نقدی، اقساط، ورودی و خروجی طلا و سود دوره.
* **تطبیق فیزیکی گاوصندوق و پیشخوان:**  
  امکان ثبت وزن فیزیکی طلای موجود و نقدینگی صندوق و مقایسه آن با مانده سیستمی جهت کشف هرگونه مغایرت یا کسری.
* **قفل اتمیک روزهای بسته شده:**  
  جلوگیری از صدور فاکتور یا دستکاری داده‌ها در روزهای کاری خاتمه‌یافته.

### ۶. انبارگردانی و بارکد
* **انبارگردانی مبتنی بر اسکن بارکد:**  
  شمارش و تطبیق لحظه‌ای موجودی واقعی با سیستم به وسیله اسکنر فیزیکی یا دوربین.
* **پشتیبانی از چاپ لیبل دمبلی طلا (ZPL):**  
  طراحی و تولید کد دستوری ZPL برای چاپ روی برچسب‌های دمبلی طلا و جواهر.

### ۷. مرکز سخت‌افزار (Hardware Integration)
* **اتصال به ترازوی دیجیتال زرگری:**  
  پشتیبانی از اتصال از طریق پورت USB Serial و Bluetooth SPP، با خواندن پیوسته فریم‌ها، پارس داده‌های وزنی، و فیلتر تشخیص ثبات وزن (Weight Stability).
* **بارکدخوان فیزیکی (HID/Keyboard Wedge):**  
  کلاس `HardwareBarcodeBus` بافر ورودی رویدادهای کلید سخت‌افزاری را به صورت آنی دریافت و به بارکد تفکیک می‌کند.
* **پرینتر صدور فاکتور حرارتی (ESC/POS):**  
  تولید بایت‌های استاندارد ESC/POS و فرمت فاکتور فارسی با فونت بهینه‌شده و رندرینگ گرافیکی دقیق.

### ۸. پشتیبان‌گیری و بازیابی داده‌ها (Backup & Restore)
* امکان تهیه فایل پشتیبان با ساختار JSON رمزنگاری‌شده به همراه هش اعتبارسنجی SHA-256 جهت جلوگیری از دستکاری دستی و تضمین بازگشت کامل پایگاه‌داده.

## 🏗️ معماری نرم‌افزار (Project Architecture)

پروژه بر اساس الگوهای **Clean Architecture** و **MVVM (Model-View-ViewModel)** با محوریت Jetpack Compose و کاتلین پیاده‌سازی شده است:

```
app/src/main/java/com/example/
├── data/
│   ├── database/       # Room Database, Type Converters (BigDecimal), DAOs
│   ├── model/          # Room Entities (Product, SaleInvoice, SaleItem, User, etc.)
│   └── repository/     # ShopRepository (مدیریت ترنزکشن‌های دیتابیس، نرخ‌های روز، تراز روزانه)
├── domain/
│   ├── usecase/        # CalculateGoldPriceUseCase, InvoiceCalculatorUseCase, BackupRestoreUseCase
│   └── util/           # BarcodeResolver
├── hardware/
│   ├── barcode/        # HardwareBarcodeBus (بافرینگ و تفکیک بارکدخوان فیزیکی)
│   ├── connection/     # درایورهای UsbSerialTransport و BluetoothSppTransport
│   ├── print/          # فرمت‌دهی فاکتور حرارتی (EscPosEncoder) و لیبل طلا (GoldLabelZplEncoder)
│   ├── scale/          # پارسر وزن ترازو (ScaleWeightParser) و بررسی ثبات وزن
│   └── HardwareManager # هماهنگ‌کننده یکپارچه اتصالات سخت‌افزاری
├── ui/
│   ├── components/     # کامپوننت‌های سفارشی اسکن دوربین و دیالوگ‌ها
│   ├── screens/        # صفحات Jetpack Compose (Dashboard, Calculator, Warehouse, Invoice, etc.)
│   ├── theme/          # استایل لوکس دارک متالیک گلد و تایپوگرافی M3
│   ├── util/           # JalaliCalendar (تقویم شمسی دقیق)، BarcodeGenerator
│   └── viewmodel/      # ShopViewModel (مدیریت متمرکز وضعیت UI و منطق بیزینس)
└── MainActivity.kt     # اکتویتی اصلی و مسیریابی صفحات
```

### ویژگی‌های فنی شاخص:
1. **دقت ریاضیاتی با `BigDecimal`:**  
   تمامی محاسبات مالی، اوزان طلا تا ۳ رقم اعشار، اجرت، سود و مالیات با استفاده از `BigDecimal` انجام می‌شود تا از خطاهای معمول ممیز شناور (`Double/Float`) جلوگیری شود.
2. **پایگاه‌داده اتمیک با Room:**  
   عملیات حساس نظیر صدور فاکتور، کسر موجودی، و ثبت تراز روزانه در بلاک‌های `@Transaction` اجرا می‌شوند.
3. **طراحی واکنش‌گرا و مدرن (Jetpack Compose):**  
   طراحی کاملاً نیتیو بدون وابستگی به وب‌ویو، همراه با انیمیشن‌های روان، حالت تاریک اختصاصی و پالت رنگی Obsidian & Metallic Gold.

## 🚀 راهنمای بیلد و اجرای پروژه (Build & Execution)

### پیش‌نیازها
* **سیستم‌عامل:** Linux / macOS / Windows
* **جاوا:** JDK 17
* **Android SDK:** حداقل نسخه API 26 (Android 8.0) و نسخه هدف API 35
* **Gradle:** پشتیبانی از Gradle Kotlin DSL (`build.gradle.kts`)

### ۱. تنظیم سکرت‌ها و وب‌سرویس نرخ طلا
این نرم‌افزار قادر است نرخ‌های زنده طلا و ارز را از وب‌سرویس دریافت کند. برای تنظیم کلید وب‌سرویس:
* فایل `.env` را در ریشه پروژه ایجاد کرده یا متغیرهای آن را در پنل **Secrets** محیط Google AI Studio تنظیم کنید:
```env
# کلید وب‌سرویس آنلاین نرخ طلا و ارز (اختیاری)
GOLD_PRICE_API_KEY=YOUR_API_KEY_HERE
```
* در صورتی که کلید وارد نشود، برنامه در حالت آفلاین کامل کار خواهد کرد و طلافروش می‌تواند نرخ روز را به صورت دستی در بخش تنظیمات یا بالای پیشخوان وارد نماید.

### ۲. اجرای تست‌های خودکار (Unit & Robolectric Tests)
تمامی آزمون‌های مالی، تست‌های مهاجرت دیتابیس و اعتبارسنجی درایورهای سخت‌افزاری با دستور زیر قابل اجرا هستند:
```bash
gradle :app:testDebugUnitTest
```

### ۳. کامپایل و ساخت فایل نصبی (APK)
برای ساخت فایل نصبی دیباگ (`apk`):
```bash
gradle assembleDebug
```
فایل خروجی نصبی در مسیر زیر تولید خواهد شد:
```
app/build/outputs/apk/debug/app-debug.apk
```
